Dihan Ahmed - Personal Portfolio Website
========================================

A modern, responsive portfolio website showcasing Data Analytics, Cloud Engineering,
and AI/ML projects. Built using the Massively template by HTML5 UP.

QUICK START
-----------
Simply open "index.html" in your web browser. That's it!

For local development with a web server:
  Python 3:  python3 -m http.server 8000
  Node.js:   npx http-server -p 8000
  PHP:       php -S localhost:8000

Then visit: http://localhost:8000

FEATURES
--------
✓ Responsive design (desktop, tablet, mobile)
✓ Parallax scrolling effects
✓ Smooth scroll animations
✓ Project showcase with images
✓ Contact information section
✓ No build process required

CUSTOMIZATION
-------------
Edit index.html to update:
  • Your name and title (line 22-24)
  • Portfolio title (line 32)
  • Project descriptions and images (starting line 48)
  • Contact information in footer (line 189-214)

Add your project images to the "images" folder and update paths in index.html.
For styling changes, edit assets/css/main.css.

DEPLOYMENT
----------
Deploy to GitHub Pages, Netlify, Vercel, or any web hosting provider.
Just upload all files and your site is live!

TECHNOLOGIES
------------
HTML5, CSS3, JavaScript, jQuery, Scrollex, Font Awesome, Google Fonts

PREREQUISITES
-------------
• A modern web browser
• Optional: Python/Node.js/PHP for local server

TROUBLESHOOTING
---------------
• Images not loading? Check that file names match in index.html
• Styles broken? Ensure assets/css/ folder exists
• JavaScript issues? Check browser console for errors
